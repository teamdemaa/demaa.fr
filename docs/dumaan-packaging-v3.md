# Packaging Dumaan, version 3

Visuel modifié avec l’outil intégré imagegen. Les versions précédentes sont conservées.

Instruction : conserver la scène de livraison, les personnes, la caisse et les grands conditionnements transparents. Remplacer les étiquettes génériques par une gamme cohérente : fond ivoire, texte brun, marque DUMAAN, nom du produit lisible, poids ou volume et indication de surgélation. Bande ocre pour les pastels (2,5 kg), terre cuite pour le mafé (2 L), sauge pour les légumes découpés (2,5 kg). Garder les aliments visibles et des soudures de sachets réalistes. Aucune certification ni allégation ajoutée.
