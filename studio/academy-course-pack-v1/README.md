# Academy course pack v1

Ce dossier contient le premier lot validé de la future Académie, sans le brancher encore sur l’interface publique. Les instructions d’intégration sont dans `HANDOFF.md`.

## Inventaire du premier lancement

### Cours fondamentaux

1. Piloter sa trésorerie
2. Comprendre chiffre d’affaires et bénéfice
3. Fixer ses prix sans vendre à perte
4. Construire son système marketing et vente
5. Transformer une demande en client
6. Déléguer sans perdre le contrôle

### Cas concret

7. JUSTE — construire un marketing tenable

## Contrat éditorial

- Aucun contenu vidéo.
- Une idée par leçon.
- Quatre à six leçons par contenu.
- Un exemple concret ou une mise en situation.
- Exactement quatre points à retenir.
- Exactement trois questions avec une explication après réponse.
- Zéro ou un CTA final, jamais deux.
- Une vignette 16:9 compréhensible sans explication.
- Les cours fondamentaux utilisent le pack d’illustrations Demaa ; les images générées sont réservées aux cas concrets qui incarnent une marque.
- Les cours restent indépendants : aucun parcours global n’est obligatoire.

## Chaîne de production

1. Transformer le script source en `CourseDefinition v1`.
2. Valider automatiquement la structure avec `scripts/validate-course-pack.mjs`.
3. Relire la clarté, l’exemple, les réponses et le CTA.
4. Produire la vignette 16:9.
5. Passer le paquet validé au moteur générique de l’Académie.

Les sept contenus sont marqués `ready`. Les fichiers de ce dossier ne modifient pas encore le comportement du site.
