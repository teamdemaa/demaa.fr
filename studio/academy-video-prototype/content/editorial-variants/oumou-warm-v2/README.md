# Paquet éditorial `oumou-warm-v2`

Version locale de travail des cinq cours Demaa. Les fichiers d’origine restent
la baseline ; chaque nouvelle narration vit dans
`content/courses/<slug>/variants/oumou-warm-v2/course.json`.

## Ligne éditoriale

- constat sans juger ;
- réalité claire ;
- explication et exemple refaisable ;
- décision ou action concrète ;
- « on » pour les erreurs fréquentes, « vous » pour les actions ;
- aucune pression, manipulation ou promesse miracle ;
- le marketing aide les personnes concernées à comprendre l’offre et à
  vérifier si elle répond à leur problème ;
- le système doit rendre le dirigeant plus autonome.
