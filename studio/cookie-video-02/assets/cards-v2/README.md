# Cartes JUSTE V2

Cette série remplace la première direction graphique.

- Fond ivoire uniforme.
- Texte brun cacao.
- Un seul accent : le point jaune.
- Aucun cadre ni ligne décorative.
- Une idée par écran.
- Composition volontairement silencieuse pour laisser respirer les photographies.

Les treize cartes sont des propositions de validation. Elles ne sont pas encore ajoutées à `approved-assets.json`.
