# Visuels demaa archivés depuis la copie sini

Les fichiers favicon.ico, icon.png et apple-icon.png présents ici sont les
anciens visuels demaa. Ils restent intacts pour historique et comparaison.
La source active de ces visuels est le dépôt demaa ; les routes d'icône de
sini utilisent désormais leurs propres images générées.
